# Address Book Management System in C

## Project Overview

A menu-driven Address Book Management System developed using C programming. It allows users to efficiently manage contact information through various operations.

## Features

* Create new contacts
* Search contacts by name, phone number, and email
* Edit existing contacts
* Delete contacts
* Display all contacts
* Validate user inputs
* Prevent duplicate entries
* Save and retrieve contacts using file handling

## Technologies Used

* C Programming
* Structures
* Arrays
* Pointers
* Functions
* String Manipulation
* File Handling

## Project Structure

* `main.c` – Main program
* `contact.c` – Contact management functions
* `contact.h` – Header file
* `contact.txt` – Contact data storage

## Learning Outcomes

* Improved C programming skills.
* Understanding modular programming.
* Practical experience with file handling.
* Improved problem-solving and debugging skills.
